# RescueBridge
*Your bridge between panic and professional help.*

## 💡 The Problem
In high-stress moments, bystanders often freeze; RescueBridge provides clear, actionable steps to help them act safely while waiting for professional help.

## 🚀 The Solution
RescueBridge is a mobile-first, privacy-focused PWA designed to guide bystanders through the first few minutes of an emergency. It provides calm, actionable steps and a structured summary for dispatchers.

## ✨ Key Features
- **Two-Step Safety:** Prevents accidental emergency calls.
- **Demo Mode:** Allows for risk-free training and demonstration.
- **Dispatcher Summary:** Generates clear, concise information to read to emergency responders.
- **Stateless & Privacy-First:** No user data is stored.

## 🛠 Tech Stack
- React, TypeScript, Tailwind CSS
- PWA (Progressive Web App)
- Web Speech API

## ⚖️ Disclaimer
This tool is for guidance only and is not a replacement for professional emergency services.
